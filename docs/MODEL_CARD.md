# 模型卡与验证边界

## 研究目标

根据速度、油门、二值刹车、挡位和场次上下文，构造多组可能的电能部署、回收和可用储能轨迹。
主场景是 2026 正赛；排位赛较弱，练习赛和排位赛功能保留为实验性研究接口。
没有获得车队真实电量、引擎图谱、实际 MGU-K 功率或保密参数。

## 计算

由速度变化估计纵向加速度，使用质量、空气阻力和滚阻假设近似轮端需求：

```
P_wheel = m*v*a + 0.5*rho*CdA*v^3 + Crr*m*g*v
P_store = P_K / eta_discharge      (P_K >= 0)
P_store = P_K * eta_charge         (P_K < 0)
E_next = E - P_store*dt
```

实现以 kW、秒、kJ 积分。正 P_K 表示电机输出，负值表示回收。储能上下限约束实际积分功率。
质量、阻力、内燃机输出、机械/电气效率和回收比例属于假设。多组假设分别积分，再形成加权估计。
正赛使用能量储备反馈的功率分配先验；SC/VSC 只随明确时间事件影响后续区间。
这不是对车队控制器的复制，也不是完整车辆最优控制求解器。

## 试跑拟合与规划

试跑模块按后续完整试跑留出验证，检查纵向加速度预测；它不能唯一识别燃油、阻力、ICE/MGU-K 分功率。
候选筛选仍保留多种参数情景；通过筛选不代表参数是真值。
满足条件时，24 路段离散规划器近似部署收益、回收代价和储能储备；不通过时回退到基础情景。
单独使用底层拟合接口时，调用方负责只提供当时已经完成的练习赛，并执行 `causalPracticeModels` 等时间筛选。
不能把未来场次、未来圈或同一试跑混入训练后宣称历史预测效果。

## 已知限制

- 缺乏真实 SOC 标签，不报告 SOC MAE、真实电量命中率或有统计覆盖保证的置信区间。
- 正赛较好是维护者使用观察；当前发布测试仅证明软件行为和数值约束。
- 排位赛的预热、冷却、充电圈与飞行圈能量目标尚不可靠，可能出现不合理轨迹。
- 初始电量未知；100% 默认值是先验。范围不会囊括所有现实情形。
- 坡度、风、尾流、轮胎、燃油、引擎模式及 MGU-H 等因素没有得到完整观测或识别。
- 默认年份、速度限制和日期条件继承现有实现；不等于已核实的最新法规。公共入口只开放 2026。
- 二值刹车不能提供实际刹车压力；轮端需求不能独立确定回收功率。
- 情景权重变化会改变中心电量，即使此时物理储能流本身没有对应变化。
- 底层接口和检查点格式可能随版本变化；只能恢复相同配置、兼容版本的检查点。

## 首版验证

公开测试使用完全合成的速度/油门/刹车序列，检查：储能与功率方向、饱和边界、连续性、重复/晚到样本、
缺测和陈旧游标、不受未来 SC 消息影响、检查点恢复，以及试跑拟合不足时的明确回退。
维护者另外用同一组合成样本核对导出代码与网站核心输出的一致性。
两者都不是独立车辆仿真验证、真实赛事准确率验证或真实 SOC 标定。

## 后续验证建议

独立动力学模拟中保留可观测的电机功率和真实储能状态，按不同未知初始电量、噪声和断流测试；
之后在获得许可且有真实储能标签的数据上开展独立测试。报告场景覆盖和失败案例，不能只展示好看的百分比。
